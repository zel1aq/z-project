## 反思

這一站我把生物從靜態做成有動態行為的個體：一葉、四葉、十六葉三種型態，平常各葉輪流收縮省能量，觸手碰到湖底就同步衝刺往上；遇到強水流會依敏感度收攏觸手；湖裡有同伴，會互相閃光回應、貼在一起融合。卡最久的是三種型態幾乎看起來一模一樣，因為葉帶糊成一條線、八面體又最亮，後來把葉片加亮、八面體壓暗，體型也依質量放大才比較分得出來。下一站想加地熱口和湖底的中心組織，讓牠跟環境的互動更明顯。
