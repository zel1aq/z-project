## 反思

這一站我看了《Our Planet》的〈Frozen Worlds〉，也查了冰下湖、冰下充水空腔（water-filled cavity）的相關文獻，還有 Lake Vostok 的 YouTube 影片。
查資料時最困難的是幾乎沒有中文資料，尤其像 water-filled cavity 這類資料幾乎找不到中文介紹。因為相關的影片和圖片也很少，只看文字時，我覺得很難理解這些構造是怎麼形成的。另外，冰下湖研究涉及很多微生物和生物相關的專業知識，所以閱讀文獻也不容易。
