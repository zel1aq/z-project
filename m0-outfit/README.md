## 反思

看到這個題目時，我聯想到之前上課聽說 AI 因為 Token 判斷方式的關係，無法算出一串點（例如：...................）有幾個。但我今天實際問 AI 卻發現他算得出來，所以我就上網查，發現有個類似的「strawberry」問題：AI 算不出裡面有幾個 "r"，但問了 AI，他還是答得出來！！！感覺 AI 進步真的很快。之後我還測試了幾個類似問題，他都能回答正確，如果不知道的也會承認，問題有誤還會糾正，太可怕了（雖然對我的作業很有幫助XDD）。
